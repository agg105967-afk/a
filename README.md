# Topics HUD（話題メモ）for Even G2

グラスに「話題のメモ」だけを表示する Even Hub アプリです。スマホ側で内容を編集できます。

既定の表示内容:

```
直近の○○楽しい/大変
▶夏休み、バイト、研究、出会い
```

## 操作

| 場所 | 操作 | 動作 |
| --- | --- | --- |
| グラス（テンプル / R1リング） | スライド（上下どちらでも） | **2ページモード時**: ページ1 ⇄ ページ2 を切り替え |
| グラス（テンプル / R1リング） | 長押し | 表示 / 非表示を切り替え |
| グラス | 長押しメニューの「隠す/出す」 | 長押しが効かないときの代わり |
| グラス | ダブルタップ | アプリ終了（確認あり） |
| スマホ（Even Realities アプリ内） | 「非表示にする」ボタン | 表示 / 非表示を切り替え |
| スマホ | 「2ページモード」スイッチ | 2ページモードの入 / 切（入れるとページ2の入力欄が出る） |
| スマホ | 「ページを切り替える」ボタン | スライドの代わり（2ページモード時のみ表示） |
| スマホ | 「グラスに表示する」ボタン | グラスへの接続に失敗したときのやり直し（接続済みなら非表示） |
| スマホ | テキスト欄を編集 | 約0.4秒後にグラスへ反映・自動保存 |

- 非表示中はグラスの表示が空白になります（編集内容は残ります）。
- アプリを開き直すと、必ず「表示」状態（2ページモードならページ1）から始まります。
- 全画面で約400〜500文字まで。超えるとグラス上でスクロールになります（上限1000文字）。

### 2ページモード

スマホの「2ページモード」スイッチを入れると、ページ2の入力欄が出ます。
グラスではまずページ1が出て、**テンプル（またはR1リング）をスライドするとページ2**、もう一度スライドするとページ1に戻ります。

- スライドの向きは問いません（上下どちらでも切り替わります）。
- ページ番号 `[1/2]` が本文の下に出ます。消したいときは `src/main.ts` の `SHOW_PAGE_NUMBER` を `false` にします。
- 非表示中のスライドは無視します（解除したときにページが変わっていないように）。
- このモード中、スライドはページ切替に使われるため、グラス上でのスクロールはできません。各ページは約400文字以内に収めてください。
- 設定（モードの入/切）とページ2の内容は保存されます。
- スライドが効かない場合は、スマホの「ページを切り替える」ボタンで同じ操作ができます。

## 動かし方

前提: Node.js 20 以上、Even Realities アプリ 2.2.10 以上（SDK 0.0.16）。

```bash
npm install
npm install -g @evenrealities/evenhub-cli @evenrealities/evenhub-simulator

# 1) シミュレーターで確認
npm run dev                          # 端末1
evenhub-simulator http://localhost:5173   # 端末2

# 2) 実機（QRでサイドロード。スマホとPCが同じLAN）
npm run dev
evenhub qr --url "http://<PCのLAN IP>:5173"   # Even Realities アプリの Scan QR で読み取り
```

### 実機に常駐させたい場合（Private build）

```bash
npm run pack      # topics-hud.ehpk を生成
```

`topics-hud.ehpk` を https://hub.evenrealities.com の開発者ポータルにアップロードし、
スマホの Even Realities アプリの Private（テスト）からインストールします。
`app.json` の `package_id`（現在 `com.kobe.topicshud`）は必要に応じて変更してください。

## ファイル構成

- `src/main.ts` グラス表示・入力処理・スマホ編集UIの制御
- `index.html` / `src/style.css` スマホ側の編集画面
- `app.json` Even Hub マニフェスト

初回起動時の表示内容を変えたいときは `src/main.ts` 先頭の `DEFAULT_TEXT`（ページ1）と `DEFAULT_TEXT2`（ページ2）を編集します。

## 注意

- 日本語や `○` `▶` が実機のフォントで表示できるかは、実機で必ず確認してください。
  フォントに無い文字は表示されず落ちます（その場合はスマホ側で別の記号に置き換えてください）。
- 長押しは、OSが「タップ→長押し」を自前メニューに使うため、状況によりアプリに届かないことがあります。
  そのため同じ操作をメニューとスマホのボタンでも用意しています。
- 起動時に「グラスに表示できません（…）」と出る場合、括弧内は各段階の結果です（例: `作成:1` = 新規作成がコード1で拒否）。
  このアプリは「新規作成 → 再構築 → メニュー無しで再構築」の順に自動で試すので、
  最後の段階まで失敗した場合は、括弧内の文字列とスマホアプリの開発者コンソールのログを控えてください。
- スライドは SDK の `SCROLL_TOP_EVENT` / `SCROLL_BOTTOM_EVENT`（テキスト欄の上端・下端でのスクロール）として受け取っています。
  実機でスライドしてもページが変わらない場合は、`listenGlassesInput` に `console.log(event)` を入れて、スライド時にどのイベントが届くか確認してください。
- 画面上部のタイトル横に版番号（例: `v0.2.0`）が出ます。更新したのに表示が変わらないときは、古いビルドが動いています。
  `.ehpk` を作り直すときは `app.json` の `version` を上げてください（ポータルで同じ版を置き換えられない場合があります）。

## PCなしで .ehpk を作る（GitHub Actions）

`.github/workflows/build-ehpk.yml` を入れてあります。このフォルダの中身を GitHub のリポジトリ（main ブランチ）に置くと、
Actions タブの「Build EHPK」→ Run workflow で `topics-hud.ehpk` が作られ、完了後に Artifacts からダウンロードできます（スマホのブラウザからでも可）。
